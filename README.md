NutriTrack KI

Projektübersicht

NutriTrack KI ist eine KI-gestützte Webanwendung zur Analyse von Ernährung und Essgewohnheiten. Ziel des Projekts ist es, Nutzern eine verständliche, datenbasierte Auswertung ihrer Ernährung zu liefern und sie bei einer gesünderen Lebensweise zu unterstützen.

Die Anwendung kombiniert moderne Frontend-Technologien mit KI-APIs, um Nährwertanalysen, Zusammenfassungen und personalisierte Hinweise zu ermöglichen.

---

Funktionen

* Analyse von Mahlzeiten und Lebensmitteln
* Automatische Auswertung von Nährwerten
* KI-gestützte Zusammenfassungen und Empfehlungen
* Übersichtliche und moderne Benutzeroberfläche
* Responsive Design für Desktop und Mobile

Installation & Start

Voraussetzungen

* Node.js (>= 18)
* npm oder yarn

Installation:
npm install

Entwicklungsserver starten:
npm run dev

Produktions-Build:
npm run build
